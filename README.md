# fuzzy-otter-mini



日常脚本的集中地

## 用法

```bash
cat data.txt | go run main.go
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/fuzzy-otter-mini.git
cd fuzzy-otter-mini
go build ./...
```
